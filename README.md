# Tender Agents

A chain of agents that finds Israeli public tenders for kindergarten and afternoon-program catering,
scores them against the business profile, and emails a daily summary for human approval.
Nothing is ever submitted automatically.

Stack: Python (FastAPI + PydanticAI), Supabase, n8n. Each agent can be paused or activated from the admin UI.
